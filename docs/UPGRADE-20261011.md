# 2026-10-11 验证与轻量化更新

保留第一原则：规则来自研究者真实项目、失败、评审及导师反馈。选取六个项目中八份已有记录，区分评审转述、导师批注总结、项目复盘和 AI 模拟评审；私有索引保存源文件 SHA-256 和查看范围，公开仅保留机制与可迁移教训。本次未验证全部原始人类评审，也没有修改原项目。

动手前确认：旧审计器要求 citation_checks、事实表与主张链接，但没有公开接口元数据核验和逐处 LaTeX 数字比对。原封存工具能验哈希，尚不能拦截宿主写入。因此新增工具，并保留原结构审计。

| 改动 | 验证与限制 |
|---|---|
| 引用身份/标题/作者/年份核验 | 合成错配、缺字段、宏、重复键与解析回归；公开 Crossref/arXiv 实跑；Semantic Scholar 部分失败保留 unresolved。元数据通过不证明引用内容或相关性。 |
| 逐处数字与事实字段比对 | 位置映射、百分比、显示舍入、零容差高精度、包含文件、变更失效检查；未知数字不能在 strict 模式通过。任意宏和图内数字需要另查。 |
| 默认三件套及升级 | 默认仅三个文件；升级保留旧记录且不自动通过门；guided/full-cycle 保留完整工作流。 |
| SymPy 搜索与数值诊断 | 精确有限反例、域过滤、未知/空域、非有限值和极小残差；示例保存失败。有限检查不证明一般定理。 |
| Claude plugin、hook、独立 agent | marketplace/manifest 静态检查、真实 stdin 协议与封存阻断、哈希失效；agent 仅 Read/Glob/Grep。Claude CLI 不可用，原生加载未验证；保护依赖加载的 hook，不是 OS 不可变。 |
| 压缩与通用 playbook | 两份长文约减少 52% 字符；独立审查科学边界和真实记录名。领域模板不是已验证的生物或社会科学方案。 |
| evals/ 基线与 CI | 冻结任务、评分、完整答案、盲化临时评分与功能回归；新增组与模型改进分开。原题设计失误、持平和接口失败均保留。 |

独立审查发现并修复了 JSON 转义、Decimal 精度、Windows 路径越界和 BibTeX 引号解析缺陷；压缩稿的两处记录名也修正并加入路径测试。没有将测试成功、文档缩短或模拟评分转成科学有效性/录用承诺。

模型对照三份证据见 [evals/](../evals/README.md)：首轮有效九题与更新版完整十题都未测到收益，当前开发题存在天花板。同模型独立上下文评分只是临时分数；更强宣传需要更难的未公开题与人工校准。
