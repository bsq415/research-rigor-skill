# Research-proposal behavioral development cases

Synthetic cases for the [proposal workflow](../skills/research-rigor/references/research-proposals.md).
These are reviewable behavioral expectations, not executed model trials or
evidence that the skill improves proposals. Existing frozen evaluation results
remain unchanged. A future comparison should freeze input artifacts and scoring,
match source/tool access, and preserve failures; a same-author walkthrough is
not independent evaluation.

## A. Improve within a protected framework

Request: Improve a five-section proposal without replacing its topic or two
RQs. It claims that all prior methods violate constraints, but a supplied primary
paper has a feasible learning output. Its own method says projection-free and
then projects every output. A local search solution is called an oracle.

Check whether the response preserves the requested topic and structure while
replacing the false novelty argument, labels the projection honestly or derives
a justified alternative, and distinguishes a local comparator from a certified
oracle. It should produce substantive in-scope revisions and traceable changes,
not silently replace the topic or preserve false claims to avoid rewriting.

## B. Rebuild a method-led proposal around a real question

Request: You may replace an old proposal built around applying a fashionable
model. The applicant has verified estimation and optimization experience. The
supplied source bundle contains a measured operational failure, an older exact
procedure and a recent application with similar terminology. No target program
is specified and no physical testbed has been confirmed.

Check whether the answer produces and compares concrete question candidates,
grounds the gap in the source mechanisms, distinguishes reused results from the
remaining obstacle, and maps demonstrated capability to a feasible plan. It
should deliver a master draft with explicit assumptions rather than wait for a
school name, invent testbed access or declare novelty from a missing keyword.

## C. An older counterexample defeats the advertised gap

Steering: An older primary paper already gives both the claimed threshold law
and its finite-sample confidence statement. The current abstract, comparison
table, work package and expected contribution all call these new. A later
reviewer's suggested fix only adds an application label to the same theorem.

Check whether the answer retracts both defeated claims, checks the suggested
fix rather than adopting it automatically, and updates all dependent locations.
It should introduce the classical procedure as a matched baseline and either
identify a consequential unproved delta or state that no contribution remains.
A narrower sentence alone must not be presented as proof of novelty.

## D. Audit a guarantee and its budget

Request: Review a proposal that gives a fixed-population high-confidence result
from n calibration samples, then promises the same confidence in each of K
groups simultaneously from n samples total. It estimates shift weights, thins a
time series and adds a monitor, claiming all three preserve the original theorem.
The model was selected on those same calibration samples.

Check whether the answer identifies the controlled quantity and randomness,
separates marginal, conditional and simultaneous statements, accounts for group
evidence and confidence allocation, and addresses selection and dependence.
It should require a justified weight-error/transfer argument and state what
the monitor actually controls. It must not equate thinning with independence,
long-run control with per-step validity, or minimum n with acquisition time.

## E. Honest reading and source-dependent correction

Request: Read all cited primary papers before finalizing the RP. The ledger has
eight full reads, five section reads and four abstracts. One search returns zero
hits even for a known title. A scanned equation was truncated in extracted text;
one full text is inaccessible. The metadata resolver reports every DOI as real.

Check whether the answer preserves the full-reading obligation, fixes/checks
the search, inspects the primary equation/page and reports reading states
accurately. It should continue accessible work and identify the exact access
need without fabricating reading or treating DOI resolution as claim support.
If all promised reading cannot be completed, it must label the handoff partial.

## F. Available information, costs and deployment

Request: A posterior-based decision proposal scores candidates using hidden
ground truth, splits neighboring samples from the same site across train/test,
and compares against a point model with fewer pilots. Its fast inference claim
omits feedback and mechanical action. All certification data come from a
simulator; the RP also promises a certified physical installation with optional
field work. Distillation is assumed to preserve uncertainty automatically.

Check whether the answer distinguishes information used for decisions from
ground-truth evaluation, repairs splits and budgets, and isolates uncertainty's
value with a matched point-decision ablation. It should separate compute from
end-to-end latency, test accelerated-model fidelity, and distinguish simulated
validity from a field claim requiring representative evidence or a justified
transfer. The repair should leave a useful methodological core and conditional
deployment extension, with consistent resources, timeline and success criteria.
